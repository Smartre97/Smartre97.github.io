# 左值和右值

# 左值 locator value

特点：
具有地址，存储在内存中，可以&取地址
表达式结束后依然存在。
通常出现在等号左边

例子：

int a = 10;     // a 是左值
int* p = &a;    // 可以取地址
a = 20;         // 可以被赋值
变量、对象、数组都是左值

# 右值

特点：
1、通常没有地址，存储在寄存器或者临时内存中
2、不能取地址（除非绑定到const左值引用）
3、通常是字面量、临时对象或表达式的中间结果。
4、通常出现在等号右边。

例子：

int x = 5 + 8;  // 13 是一个右值（字面量/临时结果）
string s = string("hello"); // string("hello") 是一个临时对象，右值
10 = y; //错误，右值不能再=左侧
int& ref = 10; //错误普通引用不能绑定右值
const int& cref = 10; //const引用可以绑定右值

# 右值分类

纯右值（prvalue） 将亡值（xvalue））

# 纯右值（prvalue）

如10、true、nullptr。

# 将亡值（xvalue））：

通过std::move转换得到的，即将销毁，但还能暂时使用的值。

总的来说，例如：
int a = b+c, a 就是左值，其有变量名为a，通过&a可以左值引用，获取该变量的地址。
表达式b+c，返回值是右值，在其被赋值给某一变量前，我们不能通过变量名找到它，＆(b+c)这样的操作不会通过编译。

# 左值引用

#include <bits/stdc++.h>
using namespace std;
int main(){
    int a=10;
    int& b=a;// b是a的引用，引用相当于变量的别名，具体通过指针实现（读取a的地址，将a的地址存入b,相当于b指向了a）
    cout<<b;//输出10
    b=20;
    cout<<a;//输出20
}
地址          内容
0x222220(a)   10
0x222230(b)   0x222220

# 右值操作

右值引入的目的是为了减少无意义的拷贝，主要与处理临时对象、转移资源、优化性能相关。
1、右值引用
2、移动构造函数与移动赋值运算符
3、std::move
4、std::forward与完美转发

# 右值引用

c++11新语法，专门用于绑定在右值上。

右值引用运行绑定右值，并对他们操作，从而避免一些不必要的复制操作，实现更高效的代码

int& a = 10; // 错误：普通引用（左值引用）不能绑定右值。
const int& a = 10; // 正确：常左值引用可以延长右值寿命，但不能修改。
int&& a = 10; // 正确：右值引用，可以修改该值。移动语义


#include <bits/stdc++.h>
using namespace std;
int main(){
    int a=10;
    int& b=a;
    b=20;

    const int&& b=20;
}

主要用途：
移动语义
完美转发

# 移动语义

移动语义用于实现移动构造函数和移动赋值运算符。通过std::move触发。

在旧c++标准中，传递和返回大型对象需要拷贝构造，这样的拷贝会造成资源浪费。

#include <string>
#include <iostream>
using namespace std;
std::string LongString() {
    string s = "大型数据对象";
    return s; //将s的值拷贝给临时对象
}
int main() {
   string str = LongString(); // 从函数返回值的临时对象拷贝给str
    return 0;
}

# 移动构造函数与移动赋值运算符

作用：不进行深拷贝（分配新内存，复制数据），而是进行资源转移（把旧对象指针给新对象，同时将旧对象指针置空）。可以说，深拷贝是复制一个文件，你会有两份文件。而资源转移是你把手中的文件给了另一个人，你手里不再有文件了，文件只存在一份。中途不进行无意义的拷贝。

class Buffer {
    int* data;
public:
    // 移动构造函数
    Buffer(Buffer&& other) noexcept {
        this->data = other.data;  // 窃取资源
        other.data = nullptr;     // 置空原对象，防止析构时释放内存
    }
};

# 移动构造函数使用案例

没有使用移动构造函数的情况

#include <iostream>
#include <utility> //为了使用 std::move

class MyBuffer {
public:
    int* data;
    int size;
    //构造函数
    MyBuffer(int s) : size(s) {
        data = new int[size];
    }

    //拷贝构造函数：深拷贝（重新申请内存，复制内容）
    MyBuffer(const MyBuffer& other) : size(other.size) {
        data = new int[size]; //又申请了一块内存
        for (int i = 0; i < size; i++) {
            data[i] = other.data[i]; //逐个复制
        }
        std::cout << "深拷贝\n";
    }

    //移动构造函数
    //注意：参数是 MyBuffer&& （右值引用）
    MyBuffer(MyBuffer&& other) noexcept {
        this->data = other.data;  //直接把对方的指针拿过来，不用开辟新内存
        this->size = other.size;

        other.data = nullptr;     //把原对象的指针置为空，防止对方析构时把内存删掉
        other.size = 0;

        std::cout << "移动构造，直接接管内存\n";
    }

    ~MyBuffer() {
        delete[] data;
    }
};

int main() {
    MyBuffer a(1000000);

    MyBuffer b = a;       //调用拷贝构造函数

    //std::move(a) 告诉编译器：把a当作右值处理，我想把它“移动”走
    MyBuffer b = std::move(a); //使用移动构造函数

    //此时，a的data变成了nullptr，b接管了那 100 万个整数的内存
    return 0;
}

# std::move

作用：强制将一个左值转换为右值（将亡值）

string s1 = "hello";
string s2 = std::move(s1); // 调用移动构造，s1 现在变为空

本质上他不是移动，至少一个类型转换，告诉编译器s1不再使用，把他当成右值拿走处理就好。

‍

move和指针赋值的区别

string a = "Hello";
string b = move(a);  // 对象级别的资源转移

// 发生的事情：
// 1. a 对象内部的字符串资源被转移给 b
// 2. a 对象本身还存在，但内容变空
// 3. 只有一份字符串数据在内存中

指针赋值

string* pa = new string("Hello");
string* pb = pa;  // 指针拷贝，两个指针指向同一内存

// 发生的事情：
// 1. pa 和 pb 都指向同一个字符串对象
// 2. 内存中只有一个字符串对象
// 3. 但有两个指针指向它

# std::forward与完美转发

作用：配合模版在范式编程转发参数，避免不必要的拷贝和移动，保持参数的原有属性（左值还是右值）
例如将一个右值传给一个模版函数时，这个右值会在函数内部成为一个有名字的变量，这会将它变为左值。std::forward可以避免这种情况，将它还原为右值。

#include <iostream>
#include <utility>

void process(int& x) {
    std::cout << "处理左值\n";
}

void process(int&& x) {
    std::cout << "处理右值\n";
}

//不使用完美转发
//写一个wrapper函数，接收参数传给proccess
template<typename T>
void wrapper(T&& arg) {
    // 这里的 arg 虽然被声明为 T&& (万能引用)，
    // 但在函数内部，arg 是有名字的变量，所以它成了左值！
    process(arg); 
}

int main() {
    int a = 10;
    wrapper(a);  // 传入左值，输出：处理左值
    wrapper(10); // 传入右值，输出：处理左值 (报错/不符合预期！)
}
//即使给wrapper传了一个右值10，但在wrapper内部，arg变成了一个有名字的左值，导致它调用的永远是 process(int&)。

//使用完美转发
template<typename T>
void wrapper(T&& arg) {
    // std::forward<T>(arg) 会根据 T 的类型
    // 决定把 arg 转发为左值引用还是右值引用
    process(std::forward<T>(arg)); 
}

int main() {
    int a = 10;
    std::cout << "传递 a (左值): ";
    wrapper(a);  //输出：处理左值

    std::cout << "传递 10 (右值): ";
    wrapper(10); //输出：处理右值
}

在写模版，例如工厂模式、智能指针内部、std::vector::emplace_black时，你不知道用户传进来的是左值还是右值，为保证效率不产生额外拷贝，必须使用完美转发将参数属性不变的传递给下一个函数
